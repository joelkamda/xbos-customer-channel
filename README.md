# XBOS Customer Channel

XC1 foundation for the XBOS Customer Channel / WhatsApp program.

This repository owns customer-channel interaction/session/transport/presentation concerns only. It does not own XBOS business truth, Gateway/provider truth, Wallet financial-product truth, or XafPay Core monetary truth.

## XC1 proof

From Windows CMD:

```cmd
XC1_RUN_ACCEPTANCE.cmd
```

The XC1 acceptance is dependency-free and runs with Python 3.13 using the standard library.
