# XC4 Catalog / Quote / Cart Constitution

1. XBOS owns catalog, commercial price, availability and authoritative quote truth.
2. Customer Channel owns presentation and interaction intent only.
3. Menu-of-the-day is an XBOS catalog/availability projection, not a Channel table.
4. The interaction cart stores refs, quantities and option selections only.
5. Every confirmation boundary obtains a fresh XBOS quote/snapshot.
6. A stale displayed price is never silently submitted.
7. Material price changes require explicit customer reconfirmation.
8. Authoritative unavailability blocks continuation.
9. XC4 creates no canonical order and no payment request.
10. Real XBOS catalog integration remains blocked until the customer-safe IA0/F facade is frozen.
